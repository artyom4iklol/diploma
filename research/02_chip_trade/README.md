## Воспроизведение

Проверено с Python 3.12 и версиями из корневого `requirements.txt`.

```bash
python -m pip install -r requirements.txt
python research/02_chip_trade/scripts/analyze.py
python research/02_chip_trade/scripts/build_report.py
```

Повторная загрузка для пересмотра данных:

```bash
python research/02_chip_trade/scripts/download_data.py --refresh
python research/02_chip_trade/scripts/analyze.py
python research/02_chip_trade/scripts/build_report.py
```

Без `--refresh` загрузчик использует сохраненный кэш. Исходные ответы включены в `data/raw/*.json.gz`, точные URL, даты и SHA256 — в `data/sources_manifest.json`. Анализ работает с этими файлами без интернета; сжатие сохраняет исходный JSON побайтно после распаковки. Несжатые копии исключены из Git.

`data/trade_panel.csv.gz` — сокращенная таблица наблюдений; `results/*.csv` — показатели и проверки; `results/*.png` — иллюстрации. Нужны годовые данные собственного экспорта Японии и Кореи за 2017–2024, пять HS6 плюс HS8542 для проверки. Preview API ограничивает один ответ 500 строками; запросы раздроблены, полнота проверяется по итогам World. При HTTP 429 используются паузы и повторные попытки.

Период пилота выбран заранее, а не объявлен последним доступным: доступность 2025 года в этой проверке не исследовалась. Обновление периода само по себе не считается новизной.

## Ограничения

Стоимостные доли включают относительные цены; прямые отгрузки не равны конечному спросу; HS8542 не охватывает всю отрасль. Декомпозиция показывает состав изменения индекса, но не причинное влияние санкций или субсидий. Восемь годовых точек на страну не превращаются в надежную причинную панель благодаря добавлению фиктивных переменных.
