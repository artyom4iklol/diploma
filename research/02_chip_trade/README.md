# Вторая тема: международная торговля интегральными схемами

**Рабочее название:** «Диверсификация экспорта интегральных схем Южной Кореи и Японии: смена рынков сбыта или изменение товарной структуры?»

**Принадлежность:** мировая экономика, международная торговля, отраслевая экономика. Объект — экспортные потоки и их структура, а не техническое устройство микросхем.

**Решение после проверки данных 15.10 и углубленного аудита 16.10.2026:** технически выполнимая тема для короткой эмпирической статьи; возможна ограниченная эмпирическая добавка, прямой повтор в проверенных полных текстах не найден. Метод не новый, два близких полных текста недоступны; гарантированная новизна не установлена. Соответствие конкретному журналу еще не проверено. Готовая научная статья пока не написана.

## Воспроизведение

Проверено с Python 3.12 и версиями из корневого `requirements.txt`.

```bash
python -m pip install -r requirements.txt
python research/02_chip_trade/scripts/analyze.py
python research/02_chip_trade/scripts/build_report.py
```

Исследовательское расширение после пилота: годовые разложения, товарные и рыночные вклады, аудит количественных полей. Первоначальный протокол и пилотные результаты не перезаписываются:

```bash
python research/02_chip_trade/scripts/publication_extension.py
```

Повторная загрузка для пересмотра данных:

```bash
python research/02_chip_trade/scripts/download_data.py --refresh
python research/02_chip_trade/scripts/analyze.py
python research/02_chip_trade/scripts/build_report.py
```

Без `--refresh` загрузчик использует сохраненный кэш. Исходные ответы включены в `data/raw/*.json.gz`, точные URL, даты и SHA256 — в `data/sources_manifest.json`. Анализ работает с этими файлами без интернета; сжатие сохраняет исходный JSON побайтно после распаковки. Несжатые копии исключены из Git.

`data/trade_panel.csv.gz` — сокращенная таблица наблюдений; `results/*.csv` — показатели и проверки; `results/*.png` — иллюстрации. Нужны годовые данные собственного экспорта Японии и Кореи за 2017–2024, пять HS6 плюс HS8542 для проверки. Preview API ограничивает один ответ 500 строками; запросы раздроблены, полнота проверяется по итогам World. При HTTP 429 используются паузы и повторные попытки.

Период исходного годового пилота выбран заранее, а не объявлен последним доступным. В последующей проверке расширения 16.10.2026 подтверждено наличие годового HS8542 за 2025 г. и памяти за декабрь 2025 г. у обеих стран; полная актуализация по HS6 и всем месяцам еще не проведена. Обновление периода само по себе не считается новизной.

## Проверка усиления для диплома

В `risk_extension/` сохранены проверка восьми близких предшественников, протокол после годового пилота, 34 основных и 12 последующих запросов месячной/годовой доступности, исходные ответы и результаты контроля. Месячный экспорт памяти доступен во всех месяцах 2024 г. для обеих стран; контроль остальных HS6 за январь 2024 г. также пройден. Импортный прокси не покрывает важные направления: запросы `Other Asia, nes` и Вьетнама за январь 2024 г. пусты. Рекомендуется исследовать концентрацию и волатильность экспортной выручки; экзогенные шоки спроса и причинный эффект ограничений на этой базе не идентифицированы. Полная месячная панель и результат о риске пока не получены.

```bash
python research/02_chip_trade/risk_extension/probe_monthly.py
python research/02_chip_trade/risk_extension/summarize_pilot.py
python research/02_chip_trade/risk_extension/probe_followup.py
```

## Ограничения

Стоимостные доли включают относительные цены; прямые отгрузки не равны конечному спросу; HS8542 не охватывает всю отрасль. Декомпозиция показывает состав изменения индекса, но не причинное влияние санкций или субсидий. Восемь годовых точек на страну не превращаются в надежную причинную панель благодаря добавлению фиктивных переменных.
