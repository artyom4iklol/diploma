# Месячная проверка для статьи

Дизайн зафиксирован до оценки полной панели в `monthly_analysis_protocol.md`. Основное сравнение — 2017/2024, 2025 г. заранее задан как отдельное расширение. Пять HS6 собираются полностью; основная оценка относится к четырем видам готовых интегральных схем, части проверяются отдельно.

## Воспроизведение

Из корня репозитория:

```bash
python -m pip install -r requirements.txt
python -m pip install -r research/02_chip_trade/risk_extension/requirements.txt
python research/02_chip_trade/risk_extension/collect_panel.py --workers 1
python research/02_chip_trade/risk_extension/build_monthly_panel.py
python research/02_chip_trade/risk_extension/analyze_monthly.py
python research/02_chip_trade/risk_extension/build_monthly_report.py
python -m unittest discover -s research/02_chip_trade/risk_extension -p 'test_monthly_method.py' -v
```

Сбор повторно использует кэш. Если сохранены годовые пакеты исходных ответов, они автоматически восстанавливаются перед запросами пропусков. `--cache-only` собирает манифест доступного кэша без новых сетевых запросов; такая неполная база не проходит контроль основного анализа. После успешного полного сбора `build_monthly_panel.py` и `analyze_monthly.py` работают без сети.

## Файлы

- `data/monthly_raw/*.jsonl.gz`: годовые пакеты исходных ответов; каждая строка содержит метаданные и исходный JSON как строку UTF-8. Это сохраняет исходные байты после декодирования строки, что проверяется по SHA256. Общий ответ двух экспортеров хранится целиком, строки выбранной страны отбираются при сборке панели.
- `data/monthly_bundle_manifest.json`: SHA256 и размеры пакетов.
- `data/monthly_manifest.json`: манифест логических ячеек страна × период × товар, URL и результаты контроля. Один общий HTTP-ответ может обслужить две такие ячейки.
- `data/collection_progress.json`: полнота сбора. 1308 логических ячеек = 1296 месячных (2 страны × 108 месяцев × 6 кодов) и 12 годовых за 2025 г. Фактическое число HTTP-запросов отличается из-за общих ответов, повторов и ранее сохраненных проб.
- `data/monthly_panel_full.csv.gz`: проверенные месячные строки, включая World; в концентрации World исключается.
- `results/monthly/`: контроль полноты и сумм, годовые веса, четыре структуры, интервалы, чувствительность, наблюдаемые темпы.
- `monthly_results.md`: автоматически собранный отчет с основным результатом и всеми предусмотренными вариантами, после прохождения контроля полной базы.
- `results/monthly/figures/`: черно-белые научные рисунки PNG/SVG, построенные из расчетных таблиц.

До окончания сбора пакеты и манифесты могут содержать **частичную базу**. Неполный срез не используется для выводов о риске. Синтетические данные из тестов не сохраняются в исследовательские таблицы.

Колебания номинальной экспортной стоимости не называются идентифицированными внешними шоками спроса. Фиксированная историческая матрица и поздние веса не являются прогнозом, доступным в начале периода. Подробные границы — в протоколе.
