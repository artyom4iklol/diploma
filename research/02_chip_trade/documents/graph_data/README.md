# Данные для 30 рисунков

`chip_trade_graph_data.xlsx` содержит 34 листа: оглавление, 30 наборов данных по расширенной программе рисунков, реестр источников и две таблицы месячных сумм. В оглавлении приведены диапазоны таблиц и нужные для графиков столбцы. Для схем 1.1, 1.2 и 3.5 даны блоки и связи.

Наблюдения относятся к экспорту Японии и Республики Корея в 2017–2024 годах, четырём кодам HS 854231, 854232, 854233 и 854239. Строки World не прибавляются к отдельным направлениям. Код 490 сохраняет наименование Other Asia, nes. Контрольная сверка с годовыми ответами дополнительно содержит 8542 и 854290, помеченные как контрольные ряды.

Простые преобразования представлены формулами Excel. Сохранённые оценки модели, разложения и доверительные интервалы перенесены без переоценки. Изменение месячных сумм в книге не пересчитывает зафиксированную модель. Рисунок 1.3 — отдельно подписанный учебный пример. Сценарии главы 3 являются условными историческими сопоставлениями, а не прогнозами или причинными эффектами.

Нумерация соответствует новой расширенной программе рисунков и может отличаться от прежних номеров в Word. Сама книга содержит данные, без встроенных диаграмм.

## Воспроизведение

1. Запустить `prepare_graph_data.py` с путём выходного JSON. Скрипт использует только сохранённую панель и результаты в этом репозитории, сверяет суммы и ключевые результаты.
2. Запустить `build_graph_workbook.mjs <JSON> <output_dir>` средой Node с установленным `@oai/artifact-tool`. В среде Codex используется bundled runtime и отдельная временная рабочая папка.
3. Проверить `validation.json`, скан формульных ошибок и изображения листов. Builder сверяет каждую формулу с независимым расчётом Python, проверяет изменение параметра учебного примера и возвращает исходное значение перед экспортом.

Исходные файлы и SHA-256 перечислены на листе «Данные». Новые запросы в Comtrade и изменения основной спецификации при сборке не выполняются.
