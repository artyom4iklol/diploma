# Дополнительная литература для исследования спадов в еврозоне

Дата проверки: 31 октября 2026 года. Автор исследования: Суховерхов Артем.

Тема: «Финансовые условия США в прогнозировании экономических спадов в еврозоне в 2007–2025 гг.»

## Итог поиска

Отобраны 14 позиций для новой вероятностной постановки. Для 11 получены и проверены полные PDF, в нескольких случаях это рабочие или авторские версии журнальных статей. Одна дополнительная публикация прочитана в официальном HTML. Две позиции пока имеют статус библиографической проверки / аннотации и не используются здесь для подробных содержательных выводов. Доступ и фактически рассмотренные версии указаны отдельно в `source_registry.json` и `access_manifest.json`.

Исходный список содержит 62 записи, включая официальную документацию и данные; это не 62 самостоятельные научные статьи. Поиск дополняет литературу по Growth-at-Risk работами о бинарных событиях, прогнозах спадов, вероятностных потерях и исторических версиях данных. Bellégo—Ferrara и Puhr с соавторами уже упоминались в `downturn_extension/SOURCE_REGISTER.md`: для них уточнены версии и расширена проверка полного текста. Они не объявляются впервые найденными исследованиями.

## Значение для научного вклада

В таблице 3 рабочей версии Bellégo—Ferrara (2009) уже присутствует американский спред BAA минус доходность однолетних гособлигаций: PDF с. 21, печатная с. 19. Поэтому сам факт использования финансового индикатора США для европейского спада не составляет нового результата. Журнальная публикация этой линии исследования датирована 2017 годом; подтверждённый издателем DOI — `10.1504/IJCEE.2017.080609`.

Рабочая формулировка вклада нашего диплома: **сопоставимая вневыборочная проверка дополнительной информации США сверх европейской базы на целевых кварталах 2007–2025 годов, с явным разделением поздней реконструированной истории и отдельного архивного упражнения**. Роль разных европейских баз, простого частотного прогноза, отдельных эпизодов и пересмотров ВВП уже проверяется в расчётах. Это описание выполненной работы, а не доказательство мирового первенства комбинации методов.

У Fiedler с соавторами прогнозируемый цикл строится на промышленном производстве; у Furno—Giannone основная задача — месячная оценка текущей рецессии. Наш основной исход — снижение реального ВВП в отдельном будущем квартале. Эти различия необходимо указывать при сопоставлении качества, а численные оценки Brier из разных работ нельзя сравнивать без учёта цели, календаря и частоты событий.

## Как использовать результаты поиска

Для теоретической главы достаточно добавить отдельный обзор исследований вероятности спада, связав его с существующими разделами о финансовых условиях и международной передаче. В аналитической главе нужны точные ссылки на FLIC, критерии оценки и версии данных. В рекомендательной главе литература помогает обосновать различие между индикатором риска, вероятностным прогнозом и правилом принятия решений.

Этот поиск не меняет зафиксированную модель, период, данные или результаты. Он не даёт основания выбирать другую спецификацию по более выгодному знаку результата. Стабильное прогнозное превосходство американских индикаторов по имеющимся расчётам не установлено; исследования международной передачи сами по себе не доказывают такого превосходства. Литературная база для написания соответствующих разделов теперь подготовлена.

## Файлы

- `READING_MATRIX.md` — краткие заметки, страницы проверенных версий и применение в дипломе.
- `source_registry.json` — библиография, ссылки, версии и статус относительно прежнего списка.
- `references.bib` — библиографические записи с примечаниями о рассмотренных версиях.
- `access_manifest.json` — результаты доступа, число страниц и контрольные суммы полученных PDF. Полные тексты использованы для чтения; здесь сохранены ссылки и реквизиты доступа.
- `SEARCH_LOG.md` — границы и метод поиска, устранение дублей и ошибок датировки.
- `validation.json` — проверки целостности этого дополнения.

Численная часть исследования: `../downturn_extension/RESULTS.md`. Исходный список источников: `../manuscript/sections/references.md`.
