# Импорт диплома в репозиторий

Добавлен 22 октября 2026 года из предоставленного пользователем архива редакции 30.

Основной текст: [manuscript/Diploma_US_Financial_Conditions_Euro_Area.md](manuscript/Diploma_US_Financial_Conditions_Euro_Area.md). Содержимое всех 968 файлов архива сохранено без потерь, включая данные, исходные ответы, литературу, программы, рисунки и историю. Пять файлов размером более 10 МиБ хранятся частями в `large_file_parts`, поскольку подключённый интерфейс загрузки ограничивает размер запроса. Чтобы восстановить исходные пути и байты, выполните из этой папки `python restore_large_files.py`. Скрипт проверяет размер и SHA256, существующие изменённые файлы не перезаписывает. Полный перечень: `LARGE_FILES.json`. Архив распакован, чтобы материалы можно было открывать непосредственно в GitHub.

Отдельно приложенный Markdown сохранён без изменений в `submitted_files`. От основного текста он отличается только относительными путями к пяти рисункам. Для чтения в репозитории следует использовать текст из `manuscript`.

Проверены размеры и SHA256 всех 967 файлов из `MANIFEST_REVISION30.json`; расхождений нет. Сам манифест не включает себя. Результаты расчётов и отчёты их проверок перенесены как предоставлены; повторная оценка модели при импорте не выполнялась.

Тема: дополнительная прогнозная информативность NFCI/ANFCI США для нижнего квантиля роста ВВП еврозоны. Работа содержит введение, три главы, заключение, список из 62 источников и четыре приложения. Описывается прогнозная информативность, причинный эффект не идентифицируется. На основной выборке американские расширения уступают HIST; небольшие улучшения ANFCI относительно базы с европейским фондовым контролем имеют ретроспективный исследовательский статус.

Исходный архивный README, инструкции воспроизведения и ограничения источников сохранены без изменений. Контрольные суммы исходных вложений и сведения об импорте: `IMPORT_AUDIT.json`.
