## Воспроизведение

Python 3.12 с numpy, pandas, scipy; версии находятся в robustness/model/requirements.txt и results/validation.json. Данные включены; сеть для расчётов не нужна. Из корня распакованного архива выполнить:

```
python robustness/model/compute.py
python robustness/model/analyze.py
python robustness/model/verify.py
```

compute.py оценивает все пять вариантов. analyze.py строит диагностики калибровки и сверяет reference с этапом 11. verify.py проверяет изменение будущих данных и создаёт разложение прогноза конца 2020 года.

model_data.csv содержит исходное полное квартальное ESI как промежуточную величину из прежнего кода. Во ВСЕХ вариантах этапа 12 оно заменяется средним первых двух месяцев непосредственно перед оценкой в compute.py; не используйте исходный столбец для отдельного прогнозирования. Обрезание gx в clip_gx выполняется внутри каждого окна, не в общем файле данных.

forecasts.csv содержит 3075 прогнозов (5 вариантов × 5 моделей × (63+60) дат). scores.csv, comparisons.csv и episode_scores.csv — потери; influence.csv — исключение одной даты из оценки без переобучения; calibration.csv — диагностики h=1 и описательные частоты h=4; calibration_h4_phases.csv — неперекрывающиеся фазы; focal_contributions.csv — арифметические вклады признаков для основной модели на 2020Q4.

MANIFEST_SHA256.json фиксирует контрольные суммы файлов. Архив проверен на целостность. Следующая работа — написание диплома после отдельного указания пользователя; новые модели сейчас не подбираются.
