# Дополнительный эксперимент, 19 октября 2026 года

Правила — PROTOCOL.md; выводы — RESULTS.md; расчёт — run_checks.py. Четыре конфигурации проверяют временной охват американских индексов и ограничение экстраполяции по текущему росту. Источники читаются из сохранённых revision16/18/19; сетевых запросов нет.

`python revision25/run_checks.py` повторяет расчёты из корня архива. `python revision25/verify_outputs.py` проверяет сохранённые результаты без оценивания моделей. Нужны numpy, pandas и scipy; использованные версии записаны в results/validation.json.

Основной исторический эксперимент не заменён наиболее удачным новым вариантом. Сравнения расширяющегося окна описательные, статистические интервалы и поправки относятся только к rolling52. Новая диагностика не добавляет независимых оценочных дат. Все результаты и ограничения приведены в chapter2/Appendix_Chapter_2_Additional_Experiments.md.
