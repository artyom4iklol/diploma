# Дополнительные проверки слабых мест второй главы

Правила зафиксированы в чате 18 октября 2026 года до просмотра новых результатов. Протокол и код восстановлены 19 октября после очистки временной среды. Результаты первоначального запуска не сохранились и не использовались при восстановлении. Известны только результаты revision18–24; весь проект не объявляется предварительно зарегистрированным.

## Исследовательские вопросы

1. Сохраняются ли выводы при ограничении американских индексов первыми двумя месяцами квартала, как у ESI?
2. Насколько сравнение зависит от экстраполяции по экстремальному текущему лаговому росту?
3. Какие разности поддерживаются вспомогательным сравнением процедур с фиксированным окном и общей поправкой на множественные проверки?

## Четыре конфигурации

- Q_raw — исходный квартальный агрегат; исходный текущий рост.
- M2_raw — первые два месяца американского индекса; исходный текущий рост.
- Q_clip_g — исходный агрегат; текущий лаговый рост ограничен минимумом и максимумом роста в допустимом обучающем окне.
- M2_clip_g — обе модификации.

Все четыре конфигурации показываются независимо от качества. Для M2 правило применяется к каждой обучающей строке и текущему кварталу. Из того же исторического снимка на конец квартала происхождения прогноза берутся недельные наблюдения соответствующего квартала с условием «дата наблюдения + 7 дней ≤ конец второго месяца». Агрегат — прежнее арифметическое среднее недель. Версия индекса не меняется: проверяется временной охват наблюдений, а не полное равенство календаря всех публикаций и пересмотров. Это не прогноз, выпускаемый в конце второго месяца.

clip_g не содержит подбираемых процентилей или множителей. Текущий рост заменяется ближайшей границей обучающего диапазона только при выходе за него. Обучающие ответы и текущие ESI/NFCI/ANFCI не меняются. Правило одинаково для всех регрессий; HIST не зависит от текущего роста. Внутри диапазона прогноз совпадает с исходным. Правило предложено после обнаружения проблемной экстраполяции: его проверка ретроспективная, без заявления о независимом подтверждении заранее выбранной стратегии.

## Неизменные элементы

Пять моделей HIST, AR, AR + ESI, AR + ESI + NFCI, AR + ESI + ANFCI; квантиль 0,10; горизонты 1 и 4; 58/55 прежних оценочных дат. Европейские данные, даты прогнозов, обучающие цели и основной/поздний оценочный факт прежние. Общие обучающие строки должны точно совпадать; при несовпадении расчёт останавливается. Используются сохранённые официальные недельные снимки. Источники revision18/19 не перезаписываются.

Для каждой конфигурации — расширяющееся и скользящее окно 52 наблюдения. Дополнительные длины окон, лаги, квантили, предикторы и правила ограничения не подбираются. Исходная проверка без пандемийных обучающих целей остаётся отдельным ранее выполненным экспериментом.

## Оценка качества и влияние дат

Главная метрика — средняя квантильная потеря. Дополнительно: частота нарушений, отношения к HIST и AR + ESI, число попарных выигрышей и последовательные одиночные исключения оценочных дат без переоценивания. Для каждой пары — полная разность, диапазон разностей после исключений и отдельно дата 2020Q4. Пять пар: NFCI/AR + ESI, ANFCI/AR + ESI, NFCI/HIST, ANFCI/HIST, ANFCI/NFCI. Новые интервалы оценки по результатам не выбираются.

## Статистическая часть

Вспомогательное формальное сравнение только для rolling52: равенство средних потерь, постоянный инструмент, двусторонний асимптотический тест с Bartlett HAC, L=4. L=8 — заранее заданная чувствительность. Показываются разность, стандартная ошибка, обычный 95%-й асимптотический интервал и p-значение. Для h=1 — единая поправка Holm на 20 сравнений (четыре конфигурации × пять пар), отдельно при каждом L. Для h=4 — отдельная дополнительная семья 20 сравнений. Это не общий контроль всех решений за историю проекта. Дополнительно сохраняются Bonferroni-интервалы для каждой семьи.

Расширяющееся окно остаётся описательным. Значимость rolling52 не переносится на него. Специальная процедура Amburgey–McCracken для вложенных квантильных моделей с пересмотрами не объявляется реализованной. Короткая выборка, неоднородность и пересмотры ограничивают надёжность асимптотики. Неотвержение не означает эквивалентности.

## Проверки исполнения

- Q_raw воспроизводит все соответствующие сохранённые прогнозы с допуском 1e−8.
- Изменение исключённых недель не меняет M2; все включённые недели удовлетворяют календарю.
- Обучающие строки, цели и оценочные даты одинаковы между конфигурациями.
- Коэффициенты воспроизводят прогноз; внутри обучающего диапазона raw и clip_g совпадают.
- Потери и нарушения пересчитываются из фактов; проверяются число строк и отсутствие дубликатов.
- Альтернативный алгоритм линейного программирования проверяет M2-расширения на датах 2011Q2, 2020Q4, 2025Q3 (последняя только h=1).
- Исходные эмпирические файлы и статьи сохраняются побайтно.

Новая удачная спецификация не заменяет исходный главный эксперимент. Итог должен разделять проверенные слабости и оставшиеся ограничения.
