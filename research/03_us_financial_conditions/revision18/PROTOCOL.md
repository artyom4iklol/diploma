# Зафиксированный протокол завершающего пилота

16 октября 2026 года. Протокол сохранён до расчёта новых прогнозов. Предыдущие результаты этапа 16 известны; это не регистрация исследования до знакомства с данными.

Вопрос: сохраняет ли NFCI дополнительную информацию о нижнем дециле роста еврозоны относительно авторегрессии с европейским ESI при исторически доступных версиях данных, и превращается ли улучшение базы в преимущество над простыми ориентирами?

Основные модели: HIST; AR; AR_ESI; AR_ESI_NFCI. Квантиль 0,10. Прямой прогноз на h=1 квартал основной, h=4 дополнительный. Цель 400/h × log(Y[t+h]/Y[t]). Константа включается во все регрессии. HIST — эмпирический дециль тех же обучающих целей. Рост-предиктор 400 × log(Y[t−1]/Y[t−2]); ESI — среднее первых двух месяцев квартала t; NFCI — среднее недель квартала t с запасом семь календарных дней до конца t. Масштабирование только на обучающей выборке.

Календарь: дата прогноза — 15-й календарный день после конца квартала t, начиная с 2011Q2 (после запуска NFCI), последняя оцениваемая дата определяется доступностью цели до 2025Q4. Дата отсечения макроэкономических снимков — конец t; допускается только снимок, соответствующий уже опубликованному к дате прогноза бюллетеню. Это уточнение прежнего дизайна, где дата прогноза была концом квартала. Оно мотивировано датами публикаций, а не новыми результатами. NFCI намеренно используется в версии на конец t, хотя к дате прогноза возможен более свежий выпуск.

RTD отражает еврозону по историческому policy concept, не фиксированный EA20. Рост считается внутри одной версии уровней; уровни разных ценовых баз не сшиваются. Для 2001–2014 берутся самостоятельные CSV-снимки официального архива, с консервативной верхней границей доступности — конец месяца выпуска Monthly Bulletin. Для 2015+ события API сопоставляются с официальным календарём Economic Bulletin. Удаление наблюдения из API не стирает ранее публично доступную информацию: при временно отсутствующем ряде сохраняется ранее опубликованное значение, с явной маркировкой возраста версии. Новые значения и доступные пересмотры за ближайшие месяцы восстанавливаются по опубликованным таблицам четырёх бюллетеней (июнь 2022, март/июнь 2023, сентябрь 2025). Это реализуемая политика сохранения ранее известных данных, а не утверждение о восстановлении каждой внутренней версии ECB.

GDP: для июня 2022 API не содержит Q1; опубликованные q/q 0,6% и y/y 5,4% преобразуются в логарифмический рост и используются как явно округлённые наблюдения для соответствующих предиктора и последних целей h=1/4. Уровень ВВП для этой заплатки не выдумывается. До оценки проводится сверка с таблицей 2.1. ESI: восстанавливаются все напечатанные месячные значения из таблицы 2.6, не только пропущенный предиктор. При сохранении старой истории ESI через смену состава еврозоны в 2023 году отмечается смешение исторических определений; чувствительность проверяется исключением этих двух прогнозных дат из оценки. Аналогичная проверка проводится по всем четырём ремонтируемым датам, без пересчёта коэффициентов, как диагностика влияния.

Обучение: кварталы 1995Q3 и позднее; на каждой дате все цели заканчиваются не позже t−1 и рассчитываются из ВВП, доступного к этой дате. Во всех четырёх моделях одна полная обучающая выборка. Расширяющееся окно — основной описательный результат; фиксированное скользящее окно 52 квартала — заранее заданная проверка и основа асимптотического сравнения прогнозных процедур по Giacomini–White. Финансовые данные до апреля 2011 используются только как история, доступная после запуска индекса, а не как реально выпущенные до запуска прогнозы.

Оценка: первая конечная точка ВВП 2025Q4. Основная фактическая цель — значение в последнем опубликованном RTD-снимке не позднее конца второго квартала после целевого квартала (примерно через шесть месяцев), с обоими уровнями из одного снимка. Это не первая флэш-оценка. Если архивный снимок не содержит нужной конечной точки, используется самый свежий более ранний полный снимок в пределах срока, а не позднейший будущий. Дополнительная цель — единая последняя версия RTD (с явной оговоркой о смене географии); используется только при оценке потерь. Основные прогнозы от выбора оценивающей версии не меняются.

Метрики: средняя квантильная потеря (меньше лучше); отношения к AR_ESI и HIST; доля фактических значений ниже прогнозного дециля (ориентир 10%). Параметры и прогнозы сохраняются на каждой дате. Изменение значений после даты прогноза не должно менять прогноз.

Неопределённость: для rolling52 — безусловный частный случай Giacomini–White с постоянным инструментом, Bartlett HAC лаги 4 (основной) и 8 (чувствительность). Это не тест причинности и не специальная процедура Amburgey–McCracken для расширяющихся вложенных моделей с пересмотрами. Три основных двусторонних сравнения при h=1: NFCI против ESI, HIST и AR; поправка Holm внутри этой семьи. При h=4 вывод вспомогательный из-за перекрывающихся целей. Все p-значения асимптотические; короткая нестабильная выборка ограничивает силу вывода. Для расширяющегося окна отношения потерь описательные, формального заявления о превосходстве по обычному DM-тесту не делается.

Устойчивость: удаление одной прогнозной даты из оценивания; оценка без четырёх ремонтируемых дат и отдельно без двух дат 2023 года; исключение пандемийных целей из обучения при сохранении всех дат оценки; подпериод 2022–2025 определяется целевыми интервалами и считается описательным. Эти проверки не используются для выбора победившей спецификации. Не требуется, чтобы NFCI победил HIST: достаточны воспроизводимый эксперимент, честное сравнение и содержательно ограниченный вывод.

Статус решения: после пилота не добавляются новые обязательные поисковые этапы. Фиксируются результаты, ограниченный вклад относительно ближайших статей и решение о начале написания. Написание глав в этом задании не выполняется.

Ограничение интерпретации календаря: на 15-й день следующего квартала третий месяц ESI и более свежие выпуски NFCI могут уже быть доступны. Они намеренно не добавляются к зафиксированному набору. Проверяется конкретная консервативная прогнозная процедура, а не наилучший прогноз со всей доступной информацией. Это ограничение не меняет вычисления и не устраняется утверждением об отсутствии календарной утечки.
