# Полнота данных и подготовка к GitHub

## Ответ на вопрос об архиве

Да, для зафиксированной эмпирической части диплома за 1995–2025 годы в полном архиве есть необходимые данные, код, исторические версии и результаты. Новое дополнение с ANFCI также имеет все 59 версий. Повторение уже полученных таблиц не требует внешнего платного доступа или нового скачивания. Проверяемая полнота зафиксирована в results/DATA_COMPLETENESS.csv и JSON.

Это не означает, что собраны все потенциально полезные мировые данные. В проекте нет полного исторического набора CISS на каждую дату; он остаётся пересмотренным ретроспективным дополнением. Отдельный контроль реальной активности США в новой модели ещё не оценён. Полные тексты есть не для всех 40 работ: 32 PDF и один HTML, семь источников с частичным доступом/метаданными. Главы диплома ещё не написаны. Эти ограничения не препятствуют воспроизведению утверждённого расчёта.

## Два назначения архивов

Полный архив — исследовательская рабочая копия с исходными скачанными материалами и прежними этапами. Его нельзя автоматически приравнивать к готовому публичному репозиторию. PDF научных статей не становятся свободно распространяемыми от того, что доступны для скачивания.

Отдельный GitHub-пакет содержит текущие данные и вычислительный код revision18/revision19, результаты, протоколы, библиографию и записку topic1. В нём нет сторонних научных PDF или полных текстов статей, старых отчётов и больших исходных ZIP; для четырёх бюллетеней оставлены только используемые статистические таблицы с атрибуцией, а исходные PDF доступны по ссылкам. Все данные, нужные для текущих расчётов, включены. Старые эксперименты с CISS целиком остаются в полном архиве, а не объявляются частью нового публичного воспроизведения.

Для GitHub нужно распаковать специальный пакет и загружать его содержимое как файлы репозитория. Полный ZIP больше 100 MiB: обычный GitHub репозиторий такой единичный файл блокирует. Это ограничение не относится к сумме маленьких файлов. Подробная инструкция находится в README GitHub-пакета.
