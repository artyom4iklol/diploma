## Результат

В исходном эксперименте NFCI и ANFCI улучшают AR + ESI, но уступают HIST; выигрыш исчезает после диагностики экстраполяции. Новая база с историческим европейским фондовым контролем уточняет вывод: небольшой выигрыш ANFCI сохраняется без экстремальной даты и при ограничении текущего роста. На полной выборке новая американская модель всё ещё уступает HIST и ограниченной исходной AR + ESI. Не утверждается ни универсальная бесполезность американской информации, ни устойчивое превосходство сложной процедуры.

Новая проверка сохраняет 58/55 дат и прежние обучающие строки. Её исследовательский статус ретроспективный; новые p-значения не вычислялись. Статус источников раскрыт отдельно: 39 полных научных работ сохранены, ещё одна полная авторская версия доступна в веб-просмотре, пять основных текстов остаются частично доступными.

## Воспроизведение

Из корня распакованного проекта:

```bash
python revision30/build_equity.py
python revision30/fit_extension.py
python revision30/make_figures.py
python manuscript/assemble.py
python manuscript/verify_manuscript.py
python revision30/verify_revision30.py
```

Сохранённых первичных файлов достаточно для расчёта дополнения без сети. Подготовленная база прежних этапов включена в архив. `fetch_sources.py` нужен только для намеренной новой загрузки; замена исходных снимков означает другую версию эксперимента. Для восстановления старых этапов см. их собственные README и программы.

Среда новых вычислений: Python 3.12.14, NumPy 2.3.5, pandas 2.2.3, SciPy 1.17.0; для чтения бюллетеней — pypdf и Poppler (`pdftotext`, `pdftoppm`), для рисунков — matplotlib. Файл `revision30/environment.json` фиксирует точные версии доступных зависимостей.

Программы `edit_manuscript.py` прошлых этапов — журналы одноразовых редакционных преобразований. Их не следует запускать поверх актуальных разделов. Итоговые отчёты проверки сохранены в `manuscript/VERIFICATION.json` и `revision30/results/FINAL_VERIFICATION.json`.
