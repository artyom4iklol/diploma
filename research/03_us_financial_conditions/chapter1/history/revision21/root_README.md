Чтение статей не заявляется независимой репликацией их доказательств и расчётов. `chapter1/REVISION_VERIFICATION.json` фиксирует проверку состава и целостности редакции.

## Эмпирическая основа и воспроизведение

Сначала читать **revision19/topic1.docx**: полноценный ответ от лица студента на пять замечаний руководителя, данные и календарь, модель и простые ориентиры, экстремальные даты, вклад и структура. В конце — отдельно обозначенный пилот ANFCI. Основа оформления и прежней постановки — приложенный diploma3; старые числа заменены проверенными результатами.

Зафиксированный исторический NFCI-пилот остаётся в revision18. Добавлены 59 исторических версий ANFCI и сопоставимый пяти-модельный эксперимент revision19. Протокол — revision19/PROTOCOL_ANFCI.md; новый результат — revision19/ANFCI_RESULTS.md. Это уточнение экономической интерпретации, а не новый метод и не причинная оценка.

При h=1 средние потери NFCI/ANFCI равны 1,634342/1,636538; HIST 1,353298. Частоты ниже прогноза NFCI/ANFCI — 27,6%/10,3%. При h=4 потери NFCI/ANFCI 1,151828/0,862621; HIST 0,747316. ANFCI улучшает некоторые свойства, но не побеждает HIST. Выигрыш относительно ESI-базы зависит от 2020Q4; порядок двух американских индексов на h=4 меняется при переходе на позднюю версию.

Даты и ограниченный исторический набор прежние: квартальная история 1995–2025, дата прогноза конец t+15, ESI первые два месяца, NFCI/ANFCI версия на конец t и семь дней запаса, цели обучения заканчиваются ≤t−1. Основная оценка — цель примерно через шесть месяцев, не первая флэш-оценка. 58/55 общих дат при h=1/4. Состав еврозоны исторический; разрывы и сохранённая история ESI раскрыты в протоколе. Результаты CISS на пересмотренных данных — отдельное дополнение, не полностью исторический эксперимент.

**Данные для зафиксированных расчётов есть полностью.** Проверка — revision19/results/DATA_COMPLETENESS.csv; пояснение — revision19/DATA_COMPLETENESS_AND_GITHUB.md. Нет полного исторического CISS, отдельный контроль реальной активности США не оценён, полные тексты есть не для всех работ (реестр 40, из них 32 PDF и один HTML). Эти границы не препятствуют повторению текущих таблиц.

Репликация без сетевых обращений из корня:

```bash
python verify_package.py
python revision18/run_all.py
python revision19/run_all.py
```

Нужны Python 3.12 и зависимости revision18/requirements.txt. Пересборка записки: `python revision19/build_topic1.py`. Для визуальной проверки Word нужен LibreOffice. Получение источников fetch_*.py отдельно и по умолчанию не запускается.

Полный архив сохраняет прежние этапы и научные тексты. Core исключает научные PDF и два больших исходных RTD ZIP; вычислительные данные остаются. Для публичного GitHub подготовлен отдельный компактный пакет с кодом и данными текущего воспроизведения, библиографией, атрибуцией и только используемыми статистическими таблицами бюллетеней. Научные PDF и полные авторские статьи в него не включены. Полный ZIP больше 100 MiB и не подходит для обычного Git commit одним файлом.

Метаданные библиографии и прежние статусы доступа относятся к полному исследовательскому архиву. Современная версия для парного NFCI/ANFCI контрфакта запрошена на 16 октября 2026 года; фактические последние колонки ALFRED датированы 15 октября. Это отличается от старой поздней выгрузки NFCI в revision18. Числа двух контрфактов не смешиваются.
