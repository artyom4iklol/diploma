## Результат исследования

NFCI и ANFCI улучшают исходную AR + ESI, но уступают HIST. Выигрыш относительно европейской базы зависит от экстремальной прогнозной даты и исчезает после диагностики экстраполяции. Некоторые диагностические европейские процедуры лучше HIST; его универсальное превосходство не заявляется. Устойчивого статистически подтверждённого превосходства американских расширений не установлено.

Новые проверки показывают: основное ранжирование сохраняется на 55 общих исходных датах; HIST лучше американских расширений после удаления любого блока четырёх последовательных дат основной процедуры; в четырёх группах неперекрывающихся годовых целей ANFCI лучше NFCI, но превосходит европейскую базу только в двух группах. Разложение потерь объясняет отличие среднего качества от частоты нарушений. Это описательные проверки сохранённых прогнозов, а не новая независимая валидация.

## Воспроизведение

```bash
python revision29/analyze.py
python revision29/build_annex.py
python manuscript/assemble.py
python manuscript/verify_manuscript.py
```

Первый шаг повторяет новые вычисления, второй формирует расчётное приложение для редакционного журнала. Актуальные семь разделов сохранены в `manuscript/sections` и являются непосредственным входом сборки. Если изменены диагностические результаты, приложение следует согласовать с соответствующим разделом; сборщик не подменяет текст автоматически.

`revision29/edit_manuscript.py` воспроизводит документированные правки редакции 28 и перезаписывает семь разделов; его не следует запускать поверх последующих ручных изменений. `revision29/install_build.py` сохраняет код установки сборщика и проверки. Полная эмпирическая основа воспроизводится прежними программами `revision18`, `revision19` и `revision25`; карта файлов находится в приложении В.

## Состав и сохранность

Все прежние исходные данные, статьи, программы и результаты сохранены. В архиве 45 уникальных научных работ в реестре: 39 имеют полнотекстовую версию, шесть доступны частично. Рабочая и журнальная версии не считаются двумя разными работами. Новые модели при этой редакции не оценивались.

Основная оценка содержит 58/55 прогнозных дат. Исходная история — 1995–2025 годы; выпуск — на 15-й день после конца квартала, ESI за первые два месяца, американские версии на конец квартала. Оценочный факт имеет ограниченную зрелость и не обязательно равен первой публикации ВВП. Состав еврозоны соответствует историческим публикациям.
