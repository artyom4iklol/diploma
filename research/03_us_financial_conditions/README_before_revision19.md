# Финансовые условия США в прогнозировании рисков роста еврозоны

Актуальная версия — revision18, 16 октября 2026 года. Решение: начинаем писать диплом. Прикладную статью можно готовить как репликацию и расширение известного дизайна; устойчивое превосходство NFCI и публикация не гарантируются. Текст глав на этом этапе не создавался.

Сначала читать revision18/Note_for_supervisor.docx (6 страниц) или revision18/FINAL_DECISION.md. Полный протокол — revision18/PROTOCOL.md; вклад и ближайшие статьи — revision18/PUBLICATION_CONTRIBUTION.md; пять замечаний руководителя — revision18/SUPERVISOR_RESPONSE.md.

Основной пилот: HIST, AR, AR + ESI, AR + ESI + NFCI; исторические версии европейских макроданных и NFCI; 10-й процентиль; h=1 основной, h=4 дополнительный; 58 и 55 общих дат. Дата прогноза — 15-й день после конца квартала; макроснимки отсечены концом квартала и связаны с опубликованными бюллетенями. ВВП текущего квартала в обучение не поступает. Информационный набор намеренно ограничен: ESI только за первые два месяца; NFCI в версии на конец квартала, семь дней буфера. Это реализуемая консервативная процедура, не полная копия всей доступной рыночной информации.

При h=1 NFCI снижает потерю относительно AR + ESI на 9,2%, но уступает HIST на 20,8%. Исключение одной даты 2020Q4 меняет выигрыш относительно базы на проигрыш. Калибровка нижнего дециля плохая. Анализ версий NFCI, окон и пандемийных обучающих целей сохраняется целиком; спецификация не выбиралась по победившему результату.

Закрыты пробелы на 59 датах предикторов; проверены 59 фактических дат регулярного ВВП и 118 выпусков ESI; 32 сверки API и старых самостоятельных снимков совпали. Новый расчёт содержит 1695 прогнозов (1356 исторических и 339 контрфактических с пересмотренным NFCI), дополнительно 144 сценария округления. Различия географии policy concept и фиксированного EA20 явно отмечены. При пробеле 2023 года сохраняется ранее публичная история ESI, в том числе старого состава; исключение этих дат показано отдельно.

Все результаты — revision18/results. Исходные RTD, два старых архива и извлечённые версии — rtd_sources. 59 версий NFCI — revision16/sources/nfci_vintages. Четыре бюллетеня для восстановления — revision18/sources. Предыдущий проект и результаты этапа 16 сохранены как ретроспективное дополнение. Исторические версии CISS не подтверждены; старое сравнение нельзя объявлять полностью реальным временем или объединять с новым пилотом в одну таблицу качества.

Реестр — catalog/registry.json: 40 уникальных работ; в полном архиве 32 PDF, один полный HTML, ещё 7 источников с неполным доступом/метаданными. Статусы прочтения и версии указаны отдельно. Карточки прежних 34 работ — review/LITERATURE_REVIEW_ALL_34.md; новые международные источники — revision16. Открытая рабочая версия Giacomini–White добавлена в revision18/sources; для Matheson PDF не получен.

Повторение без интернета из корня распакованного проекта:

```bash
python verify_package.py
python revision18/run_all.py
```

Нужны Python 3.12 и библиотеки из revision18/requirements.txt. Пересборка Word-записки отдельно: python revision18/build_report.py; для визуальной проверки потребуется LibreOffice. Скрипты fetch_*.py относятся к получению источников и при обычном воспроизведении не запускаются.

Полный и облегчённый архивы содержат одинаковый вычислительный пилот. Облегчённый архив исключает PDF научных статей и исходные большие ZIP RTD, сохраняя извлечённые версии, историю API, бюллетени, календари, код и результаты. Каждый архив имеет собственный контрольный манифест. Старые журналы неудачных запросов в rtd_sources — историческая запись поиска; окончательный результат определяется revision18/results, а не ранними тайм-аутами.
