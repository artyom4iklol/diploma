## Решение предыдущей контрольной точки

**Первоначальное решение — развивать прикладное исследование.** В рамках первых 17 спецификаций PHEV сохранял направление, HEV был чувствителен к трендам. Расширенный дизайн выше уточняет этот вывод: дополнительная фаза PHEV не выделяется устойчиво. Наблюдаемая товарная/географическая перестройка и различие количества и стоимости остаются основой работы.

Полный результат: [FULL_MODEL_DECISION_2026-10-26.md](FULL_MODEL_DECISION_2026-10-26.md). Все новые данные, модели, интервалы и диагностика: `results/full/`. Старый пилот ниже сохранён как история проверки.

Тему имеет смысл развивать как исследование **товарной адаптации поставок новых электромобилей и бензиновых гибридов из Китая в ЕС**. Простая постановка «влияние европейских пошлин на импорт китайских электромобилей» слишком близка к существующей работе Youyue Ke (2026). Собственный предмет — совместное изменение BEV, PHEV и HEV, доли Китая внутри категорий и общей структуры европейского импорта.

Рабочее название: **«Товарная адаптация поставок электромобилей и гибридных автомобилей из Китая в ЕС в условиях компенсационных пошлин»**.

Ключевой вопрос: происходило ли изменение китайской позиции преимущественно за счёт сокращения поставок BEV, расширения поставок гибридов или изменения состава всего европейского импорта? Связь со сроками торговых мер проверяется отдельно от бухгалтерского разложения.

## Данные уже получены

Источник: Eurostat Comext, DS-045409. Выгрузка 26.10.2026, версия данных обновлена 16.10.2026. Точный запрос, дата, HTTP-статус и SHA-256 исходного ответа находятся в `data/raw/eurostat_request.json`.

- Период пилота: январь 2021 — декабрь 2025, 60 месяцев.
- Импортёр: агрегат ЕС-27, постоянный состав EU27_2020.
- Происхождение: Китай, Япония, Республика Корея, США; агрегат всех внешних партнёров ЕС используется только как знаменатель.
- Скачаны восемь CN8, предусмотренных официальной автомобильной классификацией Eurostat.
- Показатели: стоимость в евро и дополнительная единица количества. Для рассматриваемых автомобилей дополнительная единица — число машин; массу нельзя использовать вместо количества.
- В возвращённой сетке 4 800 ячеек показателей, из них 4 336 наблюдаемых. Остальные оставлены пропусками. Явных числовых нулей в ответе нет.
- В основном сопоставимом наборе из трёх кодов есть все **1 800 из 1 800** значений: 3 кода × 5 партнёров/агрегатов × 2 показателя × 60 месяцев. Дубликатов ключей нет.

| Основной CN8 | Содержание |
|---|---|
| 87038010 | Новые автомобили, приводимые только электродвигателем: BEV |
| 87036010 | Новые бензиновые подключаемые гибриды: PHEV |
| 87034010 | Новые бензиновые неподключаемые гибриды: HEV |

Коды 87038090, 87036090 и 87034090 относятся к подержанным машинам и в основной набор не включаются. Дизельные гибриды 87037000 и 87035000 не разделяют новые и подержанные машины на выбранном уровне CN8; они сохранены для проверки охвата. Поэтому три основных кода нельзя называть всем автомобильным рынком или всем рынком новых электрифицированных автомобилей без уточнения охвата.

## Что показывает первый расчёт

Число новых машин китайского происхождения, ввезённых в ЕС; только три основных кода:

| Категория | 2023 | 2024 | 2025 |
|---|---: |---: |---: |
| BEV | 491 165 | 439 419 | 430 616 |
| Бензиновые PHEV | 38 931 | 42 587 | 171 348 |
| Бензиновые HEV | 7 028 | 63 830 | 130 347 |

В 2024–2025 годах количество BEV уменьшилось примерно на 2,0%, PHEV увеличилось в 4,02 раза, HEV — в 2,04 раза. Сумма по трём категориям выросла с 545 836 до 732 311 машин. Это описательное сравнение: 2024 год уже содержит месяцы действия торговых мер.

Картина по стоимости отличается: стоимость BEV снизилась с 8,878 до 6,345 млрд евро. Следовательно, необходимо отдельно анализировать число машин, стоимость и среднюю таможенную стоимость одной машины. Последняя не является очищенной ценой одинаковой модели и не измеряет розничную цену или ценовой эффект пошлины.

### Разложение доли Китая

Доля Китая в количестве внешнего импорта ЕС по трём основным категориям увеличилась с 31,23% в 2023 году до 38,83% в 2025 году: на 7,60 п.п. Симметричное разложение даёт:

- изменение китайских долей **внутри категорий**: +10,89 п.п.;
- изменение **весов категорий во всём внешнем импорте ЕС**: −3,29 п.п.

При базе 2024 года вклады другие: +4,60 и +0,96 п.п. соответственно, суммарно +5,55 п.п. Оба сопоставления сохранены; база не выбирается по удобному знаку. Тождество сложения проверено, ошибка менее 10⁻¹⁰ п.п. Метод разложения стандартный. Возможный вклад исследования — экономическое объяснение полученных компонентов в конкретном торговом эпизоде.

### Описательный регрессионный пилот

Оценены две отдельные регрессии по 60 месяцам. Зависимая величина — логарифм отношения «гибриды / BEV» для Китая минус такой же логарифм для остальных внешних поставщиков ЕС. Включены линейный тренд, календарные месяцы, июньское объявление 2024 года, фаза июля–октября 2024 и фаза ноября 2024 — декабря 2025. Для интервалов использованы Bartlett HAC с 6 и 12 лагами и поправкой n/(n−k). Это 16 параметров, поэтому модель намеренно рассматривается как небольшой пилот с ограниченной точностью.

В поздней фазе для PHEV условный множитель относительного отношения равен 7,60; асимптотический 95%-интервал при HAC(6) — [2,57; 22,45], при HAC(12) — [2,58; 22,38]. Для HEV оценка 13,14, но интервал HAC(6) чрезвычайно широк: [0,37; 466,34]; HAC(12) — [0,26; 676,97]. Результаты обеих категорий сохранены, включая неопределённый результат HEV.

**Это не коэффициенты причинного эффекта пошлин.** Они описывают относительное изменение структуры при выбранном тренде и сезонности. Не устранены специфические изменения модельного ряда и экспортной стратегии Китая. Нормальная аппроксимация при коротком периоде после мер также ограничена. Пилот подтверждает возможность вычислений, но не заменяет основной исследовательский дизайн.

## Основная модель: выполненный план

1. Сохранить основное окно 2021–2025 и отдельно рассмотреть 2022–2025 как заранее заданную чувствительность к пандемийному периоду.
2. Выгрузить данные по отдельным странам ЕС. Единица наблюдения: страна регистрации импорта × происхождение × категория × месяц. Не суммировать агрегат ЕС с его членами.
3. Оценить PPML для количества машин и отдельно стоимости. Предусмотреть постоянные эффекты пары «импортёр–происхождение–категория», эффекты «импортёр–категория–месяц» и «происхождение–месяц». Последние поглощают общие для категорий изменения экспортёра; одновременно добавлять коллинеарные валютные/макропоказатели не нужно.
4. Взаимодействия Китая, категории и фаз мер характеризуют относительную товарную перестройку. Необходимо явно задать базовую категорию. Они не дают независимых абсолютных эффектов на все категории: общий китайский месячный компонент поглощён постоянными эффектами.
5. Проверить динамику до события и совместные тренды; при нарушении не называть результат причинным. Гибриды и другие страны могут сами реагировать на тарифы, поэтому они не являются автоматически «нетронутой контрольной группой».
6. Учесть общий шок и зависимость во времени. 27 стран ввоза не превращают одну европейскую меру в 27 независимых экспериментов. Для проверок неопределённости нужен синхронный блочный анализ по месяцам с сохранением всех стран внутри временного блока; результаты сопоставляются с месячными агрегированными контрастами.

План выполнен: 19 440 национальных ячеек потока, 14 733 наблюдения в основных PPML после удаления отделённых нулевых групп, 17 оценённых спецификаций и одна неидентифицируемая проверка на непрерывно наблюдаемых потоках. Причина последней — отсутствие китайского HEV-потока, положительного во все 60 месяцев. Она явно отражена в `results/full/fit_errors.json`; коэффициент для неё не выдумывается. Замороженный внутренний план — `full_model_spec.json`; это не внешняя пререгистрация.

## Существенные границы исследования

- «Из Китая» означает страну происхождения, а не национальность владельца марки. В потоки входят в том числе западные марки с производством в Китае.
- Импорт не равен конечным продажам или регистрациям. Бельгия и Нидерланды могут выступать входными пунктами; сравнение с исключением крупных пунктов ввоза — проверка устойчивости, а не смена страны продажи.
- Новые BEV по CN8 — приближение охвата меры `ex 87038010`; юридический охват TARIC уже. Некоторые машины с ДВС-увеличителем запаса хода также охвачены мерой. Маркетинговое название «гибрид» не заменяет товарный код.
- Этапы: расследование осенью 2023 года, объявление ставок в июне 2024, временные меры в июле, окончательные — с 30 октября 2024. Для полного месячного режима используется ноябрь. Нельзя считать весь 2024 год чистым периодом до мер.
- Основная выборка заканчивается 2025 годом до просмотра результатов, чтобы использовать полные годы и не смешивать режимы. В официальном совместном заявлении ЕС–КНР от 9 октября 2026 года уже отражено новое понимание по торговле гибридами; сам факт заявления не доказывает вступление конкретной квоты в силу.
- Нельзя выводить эффект на ВВП, занятость, выбросы или прибыль производителей из этой панели торговых потоков без дополнительных моделей и данных.

## Итог расчётного этапа

Сбор и основной расчёт завершены. Решение — переходить к прикладной статье о наблюдаемой товарной адаптации. Для выбора темы дополнительная загрузка данных не требуется. Подтверждённый вклад и границы вывода зафиксированы в полном расчётном заключении. Расчётные тождества и модельные интервалы сохранены отдельно; интервалы не трактуются как доказательство причинности.

## Воспроизведение

Полный расчёт (зависимости — `requirements_full.txt`; повторная загрузка сети по умолчанию не нужна):

```bash
python research/04_auto_trade/collect_full.py
OPENBLAS_NUM_THREADS=1 python research/04_auto_trade/run_full_model.py
OPENBLAS_NUM_THREADS=1 python research/04_auto_trade/run_full_model.py --bootstrap
OPENBLAS_NUM_THREADS=1 python research/04_auto_trade/run_full_model.py --validation
OPENBLAS_NUM_THREADS=1 python research/04_auto_trade/run_full_model.py --national-validation
python research/04_auto_trade/analyze_full_accounting.py
python research/04_auto_trade/plot_full_diagnostics.py
python research/04_auto_trade/write_feasibility_decision.py
python research/04_auto_trade/validate_full_outputs.py
```

Локальный `data/model_cache/` — только пересоздаваемый кэш; в GitHub он не сохраняется. Исходный ответ Eurostat и CSV панели сохранены. Для независимого пересчёта достаточно удалить локальный кэш. Дополнительные бухгалтерские разложения по географии и средней таможенной стоимости рассчитаны после основной модели как описательная диагностика; они не выдаются за заранее зарегистрированные причинные тесты.

Пилот:

Первый скрипт использует только стандартную библиотеку Python; второй требует NumPy.

```bash
python research/04_auto_trade/collect_pilot.py
python research/04_auto_trade/analyze_pilot.py
```

При наличии исходного ответа первый скрипт по умолчанию восстанавливает панель из кэша без сетевого запроса. Для новой выгрузки нужно явно передать `--refresh`; новая версия может отражать ревизии Eurostat. Для повторного анализа уже собранной панели нужен только второй скрипт. В `data/raw/` сохранены также два пробных ответа, в которых API молча исключил непризнанные фильтры; они не являются итоговой панелью. Проверка возвращённых измерений обнаружила это, неправильные запросы не использованы в расчётах.

Основные файлы: `results/data_audit.json`, `results/pilot_panel.csv`, `results/china_new_vehicle_summary.csv`, `results/share_decomposition.json`, `results/descriptive_phase_models.json`, `results/published_total_crosscheck.json`.
