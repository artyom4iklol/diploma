## Сборка полного документа

`python research/04_auto_trade/manuscript/plot_thesis_visuals.py` создаёт полный набор иллюстраций в согласованном стиле. `python research/04_auto_trade/manuscript/prepare_full_thesis.py` обновляет введение, заключение, действительную библиографию и приложения в объединённом Markdown. `python research/04_auto_trade/manuscript/build_full_thesis.py` собирает Word через Pandoc с нативными формулами, сносками и оглавлением. Каталог временной сборки задаётся `AUTO_THESIS_BUILD_DIR`; по умолчанию используется системный временный каталог. Номера оглавления сохранены в `full_thesis_page_map.json` для проверенной версии. После содержательных или форматных изменений необходимо заново отрендерить Word, обновить номера страниц и проверить все страницы; генератор сбрасывает статус визуальной проверки. Исходные главы и предпочтительные расчётные результаты при объединении не переписываются. Перед сборкой исправленной версии должны существовать результаты `python research/04_auto_trade/audit_thesis_strengthening.py` и `OPENBLAS_NUM_THREADS=1 python research/04_auto_trade/run_thesis_model_audit.py`. Их отдельные выходы — `results/thesis_audit/`. Модуль `review_thesis_quality.py` добавляет исправления и новые проверки в полный текст. Поэтому для чтения текущей версии следует использовать `full_thesis_content.md`, а не исторические отдельные главы.
