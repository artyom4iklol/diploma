# Иллюстрации полного автомобильного диплома

29 октября 2026 года полный диплом содержит 32 логических рисунка: три в теоретической главе, 17 в аналитической, семь в рекомендательной и пять в приложении А. Рисунок А.3 состоит из четырёх отдельных панелей, поэтому в Word встроены 35 изображений.

Оформление сверено с `Diploma_Chip_Trade.docx` (версия 5) и `Diploma_Growth_at_Risk.docx` (версия 1): тёмно-синий #0b2f73, красный #e31b2d и дополнительный бирюзовый #338c86; белый фон, тонкая светлая сетка, шрифт без засечек Nimbus Sans, совместимый по назначению с Arial. Заголовок и источник находятся под изображением в Word; внутри оставлены подписи панелей, осей и рядов. Основной текст и таблицы диплома сохраняют чёрное оформление Times New Roman.

`placement_manifest.json` содержит номера и названия всех рисунков; `figure_manifest.json` — источники, контрольные суммы, тип результата и параметры стиля. Файлы JSON, а для плоских данных также CSV, сохраняют значения для построения. SVG оставляет текст редактируемым. PNG 240 dpi воспроизводятся локально и встроены в итоговый DOCX; отдельные PNG в Git не включены.

Новые изображения используют сохранённые данные Eurostat, оценки и сценарии. Сбор данных и повторное оценивание моделей не выполнялись. Схемы T01/T02 являются авторским обобщением уже рассмотренных подходов; T03 — явно условный пример HHI, а R02 — нормированный критерий расходов, не оценка прибыли. Сценарии R01 сохраняют все 18 заданных сочетаний, а R03 сопоставляет темпы разных совокупностей и не делит импорт на регистрации.

Воспроизведение из корня репозитория:

```bash
python research/04_auto_trade/manuscript/plot_thesis_visuals.py
python research/04_auto_trade/manuscript/build_full_thesis.py
```

Построение использует зависимости `requirements_full.txt`, Matplotlib, Pandas, NumPy; сборка Word — Pandoc, python-docx, lxml и Pillow. После сборки требуется рендеринг Word, сверка оглавления и визуальная проверка всех страниц. Генератор сбрасывает статус визуальной проверки. Экспорты графиков записываются атомарно, чтобы исключить публикацию частичного файла.

## Дополнение по результатам содержательного аудита

Рисунок 2.15 показывает все 16 пороговых сопоставлений исходного присутствия при базах 2023 и 2024 годов. Источник — `results/thesis_audit/baseline_presence_thresholds.csv`. Пороги строго отделяют страны с меньшим исходным количеством; при пороге 1 выделяются установленные нули. Доля выше 100% сохранена, поскольку другая группа сокращается.

Рисунок А.5 содержит все 108 индивидуальных исключений стран в четырёх сочетаниях базы и измерителя. Источники — `hhi_leave_one_country.csv` и `hhi_exclusions.csv` в том же каталоге. География и веса нормируются заново. Точки являются диагностикой влияния страны, а не доверительными интервалами; для полной географии дана отдельная штриховая линия.

Четыре панели рисунка А.3 дополнены отдельной диагностикой без NL. Источник — `exclude_NL_comparison.csv`, рассчитанный на предшествующем этапе аудита. Во всех строках показаны HAC(12), 28 прежних строк сохранены; бирюзовый цвет и ромб отличают дополнительную диагностику от основной оценки и предусмотренных чувствительностей. Новые модели для этого визуального обновления не оценивались.

В существующем рабочем каталоге только эти шесть изображений можно обновить командой `python research/04_auto_trade/manuscript/plot_thesis_visuals.py --audit-only`; остальные 29 экспортов сохраняются. Для сборки всех PNG из чистого Git checkout нужна обычная команда без флага. PNG не хранятся в Git, но встроены в Word; SVG, JSON, CSV и контрольные суммы сохранены. Библиографический PDF Ньюи–Уэста для сборки восстанавливается из URL и SHA256 в `literature/expanded/download_manifest.json`.

Проверка добавленных рисунков — `visual_revision_checks.json`: значения, интервалы, источники и снимок прежней версии на 106 страницах. Текущий документ после уточнения структуры содержит 103 страницы; итоговая верстка, 23 записи оглавления и новые номера страниц проверены в `../final_structure_revision_checks.json`.
