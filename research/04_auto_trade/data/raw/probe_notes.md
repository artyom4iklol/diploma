# Проверки запросов

В двух начальных пробах API вернул HTTP 200, но молча исключил неизвестные фильтры. В первом запросе не вернулся партнёр UK; в другом не вернулся ошибочный показатель SUP_QUANTITY. Проверка возвращённых измерений остановила сборку в обоих случаях.

Итоговая панель построена только из eurostat_pilot.json по запросу eurostat_request.json: CN, JP, KR, US, EXT_EU27_2020; VALUE_IN_EUROS и SUPPLEMENTARY_QUANTITY. indicator_discovery.json фиксирует названия доступных показателей. Начальные ответы не добавлялись в итоговую панель и не использовались для восстановления пропусков.
