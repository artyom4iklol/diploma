# diploma — проверка тем экономических исследований

Рабочие материалы для выбора тем с доступными данными и проверяемым эмпирическим вкладом.

## Темы

1. **Growth at Risk** — сохранена как отдельное направление; в этой проверке не разрабатывается.
2. **Международная торговля интегральными схемами Японии и Южной Кореи** — [паспорт, данные, код и пилот](research/02_chip_trade/README.md), [результат проверки](research/02_chip_trade/report.md).

Данные и пилот второй темы проверены 15.10.2026. [Углубленный аудит новизны 16.10](research/02_chip_trade/novelty_audit_2026-10-16.md) не выявил прямого повтора в проверенных полных текстах; возможна ограниченная эмпирическая добавка. Метод не новый, ограничения доступа к двум близким работам сохранены. Требования площадки неизвестны. Материалы не являются готовой журнальной статьей.

## Как проверять следующую тему

[Краткий протокол отбора](research/SCREENING.md). Не путать новизну результата с процентом текстовой уникальности.

Для воспроизведения вычислений нужны Python 3.12 и зависимости из `requirements.txt`; инструкции находятся в папке темы. Сохраненные исходные данные позволяют выполнить анализ без повторных запросов к API.
